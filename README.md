# Ai-DysonASI--v5.2

This repository is the project for **Ai-DysonASI 5.2** developed by **Chinmay Bhatt**.

## Project Overview

Ai-DysonASI 5.2 is an advanced version of the DysonASI project. It incorporates AI-powered functionality to provide a personalized chatbot experience. The chatbot, built using the Gemini API, is designed to assist users with a wide variety of tasks, handle document uploads, and generate responses based on content analysis.

## Features
- **Chatbot Integration:** Utilizes Gemini API to provide intelligent responses.
- **Document Upload Support:** Allows users to upload documents for content-based AI responses.
- **Predefined Responses:** The chatbot can answer common queries with predefined responses before reaching out to the Gemini API.
- **MongoDB Integration:** Chats are saved in MongoDB, allowing users to retrieve past conversations easily.
